# HR Analytics Dashboard

An interactive HR Analytics Dashboard built using Power BI to analyze employee attrition, workforce demographics, job satisfaction, and departmental trends. This project helps HR teams and business stakeholders make data-driven decisions by identifying patterns related to employee retention and workforce behavior.

---

## 📌 Project Overview

This project focuses on analyzing HR data to uncover insights such as:

- Employee attrition trends
- Department-wise attrition
- Gender distribution
- Age group analysis
- Education field analysis
- Job satisfaction ratings
- Active employee statistics

The dashboard provides a visual and interactive way to monitor workforce metrics and improve HR decision-making.
